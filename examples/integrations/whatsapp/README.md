Send `GET /v1/charts/{id}/share/whatsapp` after setting `Ploteus:Interactive:PublicBaseUrl` to HTTPS. The returned `native.cloudApiMessageTemplate` is a safe server-generated text message with preview. Supply an authorized `to` E.164 number, `PHONE_NUMBER_ID`, provider access token and permissions in your sending service. Ploteus does not store credentials or send WhatsApp messages.
