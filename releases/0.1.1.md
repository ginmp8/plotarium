# Release 0.1.1

## Implementado

- Remocao integral de autenticacao: inicializacao sem Plotarium__ApiKey, nenhuma chave/token/header exigido, nenhum middleware de autenticaçao. Endpoints de render/capabilities/health publicos no processo.
- Preservacao do contrato POST /v1/render (`spec` para ECharts/Plotly; `source` para Mermaid), com exemplos curl corrigidos.
- Retirada do bloqueio PuppeteerSharp/NuGet: protocolo CDP nativo .NET 10, mantendo asset pinado, limitacoes, validacao e formatos incluindo PDF.
- OpenAPI e documentacao de operacao/seguranca atualizadas; testes HTTP anonimos e casos de regressao 400/404.

## Evidencias

- Release build/publish: zero erros/avisos.
- 75 contract checks; 24 HTTP integration checks (18 engine/format).
- PNGs inspecionados visualmente e PDFs com uma pagina valida por engine.
- Browser instalado pelo operador; validacao de Chromium com sandbox DESABILITADO apenas no contêiner Development, nao liberado para producao.

## Aviso de rede

Nao exponha o servico anonimo diretamente a Internet. Restrinja a interface a loopback ou rede protegida. `docs/security.md` descreve os limites e riscos residuais.

- Removido `src/infrastructure/Plotarium.Infrastructure/renderer.js`, adaptador PuppeteerSharp nao referenciado. Substituido por `render-bridge.js` + CDP nativo.
